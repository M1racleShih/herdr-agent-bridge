# Project mascot

English · [简体中文](README.zh-CN.md)

The beaver carries a message across a bridge, just as a coding result travels back to the chat that requested it. The project commissioned the original design using OpenAI image generation. The color vector and one-color artwork were traced from that design. The artwork ships under the [Apache-2.0 license](../../LICENSE).
